# stoelner-preiskalkulation

Sammlung interner Stölner-Web-Tools.

## Tools

- **Preiskalkulation** (`index.html`) — Anwendung zum Kalkulieren von Ersatzteilpreisen
  (Staffelfaktoren, ATS/EUR, Stapelkalkulation, WinLine-Export). Reines Single-File-HTML.
- **Balanced Scorecard** (`bsc/`) — abteilungsübergreifende Unternehmens-BSC mit
  Backend, Login pro Abteilung, Ampel-Cockpit, Kennzahlen-Trends, Maßnahmen und
  Live-Aktualisierung. Siehe [`bsc/README.md`](bsc/README.md).
